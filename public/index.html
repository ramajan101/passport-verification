⚠️ Passport Seva Kendra (PSK) Verification Guidelines:
  • Name Spelling: Name should match 100% across Aadhaar, PAN, and 10th Marksheet. Any spelling variation (even 1 letter) requires Annexure-D affidavit or document correction.
  • Gender (Male/Female): Gender must match strictly across all identity records.
  • Date of Birth (DOB): 10th Marksheet / Birth Certificate takes precedence for official passport issuance.
